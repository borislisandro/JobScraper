# Packaged offline BGE model

Release preparation fetches `BAAI/bge-small-en-v1.5` compatible Xenova ONNX
files at pinned revision, then verifies every size and SHA-256 from
`scripts/bge-small-en-v1.5.manifest.json`. These generated bytes are ignored by
Git but bundled under `models/bge-small-en-v1.5`.

`model.onnx` is stored at the model-directory root because that is the exact
runtime path consumed by `embedding.rs`; the upstream file lives under
`onnx/model.onnx`.

Attribution: BAAI/bge-small-en-v1.5 (MIT; commercial use permitted by model
card), converted ONNX assets from Xenova/bge-small-en-v1.5. Runtime uses
FastEmbed's user-defined in-memory loader only; it never invokes HF Hub or a
model download path.
